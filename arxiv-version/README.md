# PURPOSE

Directory for loading the standard to Arxiv.

The instructions on how to do this are [here](https://trevorcampbell.me/html/arxiv.html)

Basically this amounts to flatten the file, put all the images in this directory, along with the bibliography, the BBL file.

# INSTRUCTIONS

1. `cp ..\miracle-specification-full.tex .`
2. edit this file and remove all the "img/" prefixes from the image paths.
3. `pdflatex miracle-specification-full`
